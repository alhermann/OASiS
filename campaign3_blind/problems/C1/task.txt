Solve the following boundary value problem as a COUPLED simulation using TWO codes: 4C (write a YAML input file and run the 4C binary) on subdomain A and FEniCSx (dolfinx) on subdomain B.

GLOBAL DOMAIN: the {2: 'rectangle', 3: 'box'}[2] (0, 1.5) x (0, 1)
SUBDOMAIN A: A = (0, 0.625) x (0, 1), k = 3, lambda = 600, mu = 400
SUBDOMAIN B: B = (0.625, 1.5) x (0, 1), k = 1, lambda = 600, mu = 1600
INTERFACE: the line x = 5/8, where the two materials meet
EQUATION: in each subdomain, BOTH of
           -div(k grad T) = f_T
           -div(sigma_tot(u, T)) = (f_x, f_y), with
           sigma_tot = 2*mu*sym(grad(u)) + lambda*div(u)*I - beta*T*I   (plane strain, small strain)
COEFFICIENTS: subdomain A: k = 3, lambda = 600, mu = 400 (E = 1040, nu = 3/10); subdomain B: k = 1, lambda = 600, mu = 1600 (E = 40000/11, nu = 3/22). NOTE: the two transmitted fields have very different interface stiffnesses (both follow from the conductivities, Lame parameters and subdomain widths above). A single scalar relaxation factor chosen for one can diverge in the other; a per-block or worst-block choice is safer.
OUTER BOUNDARY CONDITIONS: T = 0 and u = 0 (both components) on the entire outer boundary
INTERFACE CORNERS: at the points where the interface meets the outer boundary, the outer boundary condition above applies on BOTH subdomains. Those points belong to the outer boundary, not to the interface, on either side.
INTERFACE CONDITIONS: the temperature, the displacement vector, the normal heat flux and the traction sigma_tot.n (all components) must be continuous across the interface. Achieve this by exchanging interface data between the two codes and iterating until the interface mismatch is below 1e-6 relative.
COUPLING SCHEME: a partitioned Dirichlet-Neumann iteration, with subdomain A as the DIRICHLET side and subdomain B as the NEUMANN side. The DIRICHLET side receives the interface FIELD from its partner, imposes it as an essential boundary condition on the interface, and returns its own outward normal flux and traction there. The NEUMANN side receives that flux and traction and applies it as a natural boundary condition on the interface, and returns its own interface field. These roles are prescribed: solve with them as stated rather than choosing your own.
DISCRETISATION: Lagrange P1 for the temperature and vector Lagrange P1 for the displacement, in both codes
MESH SEQUENCE: uniform meshes, h halved per level: h = 1/8, 1/16, 1/32
