Solve the following boundary value problem as a COUPLED simulation using TWO codes: FEBio (write a .feb deck and run the febio4 binary) on subdomain A and deal.II (build and run the C++ program) on subdomain B.

GLOBAL DOMAIN: the rectangle (0, 1.5) x (0, 1)
SUBDOMAIN A: A = (0, 0.625) x (0, 1), lambda = 500, mu = 250
SUBDOMAIN B: B = (0.625, 1.5) x (0, 1), lambda = 500, mu = 1250
INTERFACE: the line x = 5/8, where the two materials meet
EQUATION: -div(sigma(u)) = f, sigma(u) = 2*mu*sym(grad(u)) + lambda*div(u)*I   (plane strain, small strain)
COEFFICIENTS: subdomain A: lambda = 500, mu = 250 (E = 2000/3, nu = 1/3); subdomain B: lambda = 500, mu = 1250 (E = 20000/7, nu = 1/7). The shear modulus jumps across the interface; lambda is the same on both sides.
SOURCE TERM: f(x, y) =
               f_x = x**2*y**3/50 + 6*x**2*y**2/125 - 33*x**2*y/500 + 3*x**2/250 - x*y**3/50 - 6*x*y**2/125 + 33*x*y/500 - 3*x/250 + y**5/125 + 4*y**4/125 - 89*y**3/500 - 21*y**2/125 + 297*y/1000 - 27/500   (subdomain A)
               f_y = -3*x**2*y**2/100 - 6*x**2*y/125 + 33*x**2/1000 + 3*x*y**4/100 + 12*x*y**3/125 - 279*x*y**2/500 - 63*x*y/125 + 99*x/250 - y**4/200 - 2*y**3/125 + 33*y**2/1000 - 3*y/250   (subdomain A)
               f_x = -101*x**2*y**3/1470 - 202*x**2*y**2/1225 + 1111*x**2*y/4900 - 101*x**2/2450 + 11869*x*y**3/18375 + 47476*x*y**2/30625 - 130559*x*y/61250 + 11869*x/30625 - 101*y**5/6125 - 404*y**4/6125 - 9591*y**3/39200 - 274761*y**2/245000 + 2755731*y/1960000 - 250521/980000   (subdomain B)
               f_y = 33183*x**2*y**2/24500 + 66366*x**2*y/30625 - 365013*x**2/245000 - 101*x*y**4/2100 - 404*x*y**3/2625 - 17141*x*y**2/9800 - 104794*x*y/30625 + 1113849*x/490000 + 499*y**4/3675 + 7984*y**3/18375 - 41347*y**2/49000 + 2509*y/6125 - 5643/98000   (subdomain B)
OUTER BOUNDARY CONDITIONS: u = 0 (both components) on the entire outer boundary
INTERFACE CORNERS: at the points where the interface meets the outer boundary, the outer boundary condition above applies on BOTH subdomains. Those points belong to the outer boundary, not to the interface, on either side.
INTERFACE CONDITIONS: the displacement vector and the traction sigma.n (BOTH components) must be continuous across the interface. Achieve this by exchanging interface data between the two codes and iterating until the interface mismatch is below 1e-6 relative.
COUPLING SCHEME: a partitioned Dirichlet-Neumann iteration, with subdomain A as the DIRICHLET side and subdomain B as the NEUMANN side. The DIRICHLET side receives the interface FIELD from its partner, imposes it as an essential boundary condition on the interface, and returns its own outward normal traction there. The NEUMANN side receives that traction and applies it as a natural boundary condition on the interface, and returns its own interface field. These roles are prescribed: solve with them as stated rather than choosing your own.
DISCRETISATION: vector Lagrange P1 elements in both codes
MESH SEQUENCE: uniform meshes, h halved per level: h = 1/8, 1/16, 1/32


REQUIRED OUTPUT (this is how your work is assessed; follow it exactly):

(1) FIELD. Your solution is assessed at FIXED probe points that do not depend on
your mesh, defined separately for each subdomain. For every mesh level and for
EACH subdomain, evaluate your computed solution at every probe point of that
subdomain and write one CSV file
    solution_level<k>_<side>.csv        (k = 1,2,3,...; side = A or B)
with a header line and one row per probe point, in the order defined below:
    x, y, ux, uy

PROBE POINTS, subdomain A: the 1936 points given by x = 0 + (i_x+0.5)*0.625/44; y = 0 + (i_y+0.5)*1/44, for i_x, i_y = 0, 1, ..., 43 independently, ordered with the last index varying fastest
PROBE POINTS, subdomain B: the 1936 points given by x = 0.625 + (i_x+0.5)*0.875/44; y = 0 + (i_y+0.5)*1/44, for i_x, i_y = 0, 1, ..., 43 independently, ordered with the last index varying fastest
Evaluate (interpolate) your finite element solution at these points. They are
deliberately not mesh nodes. Write full precision; every probe point must
appear exactly once and no other points may appear.

PRECISION: write every value with AT LEAST 12 significant digits (for
example the format %.11e). Values rounded to fewer digits do not carry the
information the assessment needs and the submission is rejected.

(2) INTERFACE. For every mesh level and EACH subdomain, write
    interface_level<k>_<side>.csv
with a header line and one row per interface probe point, in this order:
    x, y, ux, uy, tx, ty
where (tx, ty) is that subdomain's OUTWARD normal traction t = sigma(u) . n_out, evaluated from
that subdomain's own solution and its own material, with the unit normal
pointing OUT of that subdomain. The two subdomains therefore use opposite
normals at the same physical point.

INTERFACE PROBE POINTS: the 44 points (x, y) = (5/8, 1/4 + (i+0.5)*1/2/44) for i = 0, 1, ..., 43. These cover the INTERIOR of the interface only: where the interface meets the outer boundary the split problem has a Dirichlet-Neumann corner, the recovered flux there does not converge under refinement, and those points are therefore not graded

(3) COUPLING HISTORY. For every mesh level write

with a header line and one row per coupling iteration:

listing the relative interface mismatch at every iteration of your partitioned

(4) Then write the single summary file `RESULT.txt` with exactly these lines:

Both codes named below must actually run and must exchange interface data;

MESH_INDEPENDENCE solely from how your own solution behaves under refinement,
