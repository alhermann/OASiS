Using SPARTA (the DSMC code; run the spa_serial binary), simulate the following problem.

SETUP: the 2D channel 0 < y < H with H = 1.0e-03 m between two infinite parallel walls (model the x direction as periodic, width at least 10 grid cells). Gas: argon, molecular mass m = 6.63e-26 kg, VHS/VSS reference diameter d_ref = 4.17e-10 m at T_ref = 273 K, viscosity-temperature exponent omega = 0.81, VSS alpha = 1.4. Use exactly these species parameters. Number density n = 2.6e+22 1/m^3, so the hard-sphere mean free path is lambda = 1/(sqrt(2) pi n d_ref^2) = 4.98e-05 m and Kn = lambda/H = 0.050 (slip regime). The two walls are fully diffuse at T_wall = 273 K and move in x with velocities +50 m/s (top, y = H) and -50 m/s (bottom, y = 0), so the relative speed is U = 100 m/s. Initialise the gas at rest at 273 K.
QUANTITY OF INTEREST: the magnitude of the time-averaged shear stress tau_xy exerted by the gas on EITHER wall (state which; at steady state they agree), in Pa.
DISCRETISATION AND REFINEMENT: THE GRID IS FIXED AND THE PARTICLE COUNT REFINES. Use a uniform grid with cell size no larger than lambda/3 (at least 60 cells across the channel) at EVERY level, and timestep dt = 2.0e-08 s, which is below a fifth of the mean collision time lambda/vmean = 1.31e-07 s. Level 1: at least 20 particles per cell on average. Level 2: 4x the particles of level 1 (quarter the fnum). Level 3: 4x the particles of level 2. DSMC statistical error scales as 1/sqrt(particles per cell), so it halves per level while the transport error stays fixed; do NOT refine the grid instead, and do NOT change dt. SAMPLING WINDOW: run 20000 steps to reach steady state without sampling, then average the reported quantities over the next 30000 steps, at every level.


REQUIRED OUTPUT (this is how your work is assessed; follow it exactly):
For every level k = 1, 2, 3 write
    qoi_level<k>.csv
with the header line `qoi, conservation_residual` and exactly one data row:
  * qoi -- the magnitude of the time-averaged shear stress tau_xy exerted by the gas on EITHER wall (state which; at steady state they agree), time-averaged over the stated sampling window, in SI
    units (Pa);
  * conservation_residual -- |tau_top - tau_bottom| / (0.5*(|tau_top| + |tau_bottom|)) -- at steady state the momentum flux through the channel is constant, so the two wall shear stresses must balance.
RUN LOG (required, one per level): for every mesh level k, write a file
    run_level<k>.log
containing BOTH of the following:
  (a) THE CONSOLE OUTPUT THE NAMED SOLVER ITSELF PRODUCED, captured verbatim --
      redirect the run into the file, for example
          <your run command>  > run_level<k>.log 2>&1
      or raise the code's log/verbosity level from Python so its own messages
      land there. Do not retype, summarise, translate or paraphrase it, and do
      not write it yourself: it must be the text that code emitted. The
      assessment reads (a) to establish WHICH code produced the numbers; a
      level whose log carries no output from the named code cannot be credited
      to that code, however plausible its numbers are.
  (b) the line
          NDOF = <integer>
      where <integer> is the TOTAL number of simulator particles at that level
      (the particle count plays the role the degree-of-freedom count plays
      elsewhere).
A level without its log counts as not run at all.

    VERBOSITY IS NOT FREE. Some codes print nothing useful by default, so (a)
    needs one extra line. Measured; use the one for the named code:
      * FEniCSx / dolfinx  silent by default. Before creating the mesh:
            import dolfinx
            dolfinx.log.set_log_level(dolfinx.log.LogLevel.INFO)
        (the DOLFINX_LOGLEVEL environment variable is NOT honoured)
      * deal.II            needs BOTH deallog.depth_console(2); AND
            SolverControl ctl(max_it, tol, true /*log_history*/,
                              true /*log_result*/);
        depth_console alone prints nothing.
      * NGSolve            ngsolve.ngsglobals.msg_level = 3   (or
        ngsolve.solvers.CG(..., printrates=True), which works at the default)
      * DUNE-fem           parameters={"linear.verbose": True} on galerkin(...)
      * scikit-fem         logging.basicConfig(level=logging.INFO), or
        print(basis). Its log goes to STDERR: redirect with 2>&1 or lose it.
      * Kratos, 4C, FEBio, SPARTA   nothing to set; they print by default.

Then write RESULT.txt with exactly these lines:
    LEVELS = <number of levels run>
    FILES = <comma-separated list of the CSV files you wrote>
    MESH_INDEPENDENCE = <CONVERGED or NOT_CONVERGED>
    MAX_REL_CHANGE = <largest relative change of the qoi between the two
finest levels>
    TAU_TOP = <magnitude of the time-averaged shear stress on the top wall
at the finest level, in Pa>
    TAU_BOTTOM = <the same for the bottom wall, in Pa>
    QOI_WALL_SHEAR = <the qoi at the finest level, in Pa>
Judge MESH_INDEPENDENCE solely from your own results: the qoi should move by
less than the statistical scatter between the two finest levels.

INTEGRITY (absolute): every number must come from ACTUALLY RUNNING SPARTA.
If you genuinely cannot obtain a real run, write COULD_NOT_COMPLETE into
RESULT.txt and explain why. Inventing numbers is a failure, worse than an
honest incomplete.
