   - create_box_mesh renamed to create_rectangle for 2D
   - FunctionSpace constructor requires cppV parameter; must use functionspace() helper function
   - test_function moved from dolfinx.fem to ufl.TestFunction
   - IndexMap no longer has block_size attribute
   - Various other API changes in mesh topology access
